# AIPSEBioBook
Repository for examples in the book AI in Process Systems Engineering - Modelling Biomass Conversion
The code is for the following chapters
Chapter 3. Introduction to data processing and analysis
Chapter 4. Applications to biomass characterization
Chapter 5. Applications to physicochemical properties
Chapter 6. Applications to experimental reaction data
Chapter 7. Applications to process optimization
Chapter 8. Hybrid modelling for processes

INSTRUCTIONS.
Load the folders with the code and dataset .csv files in Colab or Jupyter Notebook. Make sure you have the dataset files in the same folder as the notebook.
Test the code
